# Python - More Classes and Objects

This project continues Object-Oriented Programming in Python. It covers
defining classes with private attributes, properties, class methods,
static methods, special methods (`__str__`, `__repr__`, `__del__`),
and class attributes.

## Tasks

- **0-rectangle.py**: Empty class `Rectangle`
- **1-rectangle.py**: `Rectangle` with private `width` and `height` attributes
- **2-rectangle.py**: `Rectangle` with `area()` and `perimeter()` methods
- **3-rectangle.py**: `Rectangle` with `__str__()` method
- **4-rectangle.py**: `Rectangle` with `__repr__()` method
- **5-rectangle.py**: `Rectangle` with `__del__()` method
- **6-rectangle.py**: `Rectangle` with `number_of_instances` class attribute
- **7-rectangle.py**: `Rectangle` with `print_symbol` class attribute
- **8-rectangle.py**: `Rectangle` with `bigger_or_equal()` static method
- **9-rectangle.py**: `Rectangle` with `square()` class method
