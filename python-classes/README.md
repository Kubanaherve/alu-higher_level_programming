# Python - Classes and Objects

This project introduces Object-Oriented Programming (OOP) in Python. It
covers defining classes, creating objects, using private attributes,
properties, getters and setters, and writing public methods.

## Tasks

- **0-square.py**: Empty class `Square`
- **1-square.py**: `Square` with private `__size` attribute
- **2-square.py**: `Square` with size validation
- **3-square.py**: `Square` with `area()` method
- **4-square.py**: `Square` with getter/setter for `size`
- **5-square.py**: `Square` with `my_print()` method
- **6-square.py**: `Square` with `position` attribute and full printing
