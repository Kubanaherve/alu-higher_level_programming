# Python - Exceptions

This project covers Python exceptions: the difference between errors and
exceptions, how to catch and handle exceptions with try/except/finally,
and how to raise built-in exceptions.

## Tasks
0. `0-safe_print_list.py` - safely print x elements of a list
1. `1-safe_print_integer.py` - safely print an integer
2. `2-safe_print_list_integers.py` - print and count only integers in a list
3. `3-safe_print_division.py` - divide two integers with a finally block
4. `4-list_division.py` - divide two lists element by element
5. `5-raise_exception.py` - raise a TypeError
6. `6-raise_exception_msg.py` - raise a NameError with a message
