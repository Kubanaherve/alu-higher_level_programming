# JavaScript Objects, Scopes and Closures

Classes, inheritance and closures (no `var` where specified).

| File | Description |
|---|---|
| `0-rectangle.js` | Empty `Rectangle` class |
| `1-rectangle.js` | `Rectangle(w, h)` sets `width`/`height` |
| `2-rectangle.js` | Empty object if `w`/`h` is 0 or not a positive integer |
| `3-rectangle.js` | Adds `print()` with `X` |
| `4-rectangle.js` | Adds `rotate()` and `double()` |
| `5-square.js` | `Square(size)` extends `4-rectangle.js` via `super(size, size)` |
| `6-square.js` | Extends `5-square.js`, adds `charPrint(c)` (default `X`) |
| `7-occurrences.js` | `exports.nbOccurences(list, searchElement)` counts occurrences |
| `8-esrever.js` | `exports.esrever(list)` reverses without `reverse()` |
| `9-logme.js` | `exports.logMe(item)` prints `<count>: <item>` with closure counter |
| `10-converter.js` | `exports.converter(base)` returns base converter, no new variables |
