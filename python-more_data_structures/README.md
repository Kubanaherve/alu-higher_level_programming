# Python - More Data Structures: Set, Dictionary

Project covering Python sets, dictionaries, lambda, and map functions.

## Learning Objectives

- What are sets and how to use them
- Most common set methods and when to use them
- When to use sets versus lists
- What are dictionaries and how to use them
- When to use dictionaries versus lists or sets
- What is a lambda function
- What are map, reduce and filter functions

## Tasks

| File | Description |
|------|-------------|
| `0-square_matrix_simple.py` | Compute square value of all integers of a matrix |
| `1-search_replace.py` | Replace all occurrences of an element in a list |
| `2-uniq_add.py` | Add all unique integers in a list |
| `3-common_elements.py` | Return common elements of two sets |
| `4-only_diff_elements.py` | Return elements in only one set |
| `5-number_keys.py` | Return number of keys in a dictionary |
| `6-print_sorted_dictionary.py` | Print dictionary by ordered keys |
| `7-update_dictionary.py` | Replace or add key/value in a dictionary |
| `8-simple_delete.py` | Delete a key in a dictionary |
| `9-multiply_by_2.py` | Return new dictionary with values multiplied by 2 |
| `10-best_score.py` | Return key with the biggest integer value |
| `11-multiply_list_map.py` | Multiply list values using map |
| `12-roman_to_int.py` | Convert Roman numeral to integer |

## Requirements

- Python 3.8.5
