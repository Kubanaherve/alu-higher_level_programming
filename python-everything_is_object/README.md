# Python - Everything is object

This project explores Python's object model, focusing on the
difference between mutable and immutable objects, how variables
reference objects, and how Python manages memory.

## Tasks

- **0-answer.txt** to **18-answer.txt**: Quiz questions about
  object identity, mutability, and Python's behavior.
- **19-copy_list.py**: Function that returns a copy of a list.
- **20-answer.txt** to **28-answer.txt**: More quiz questions
  about tuples, identity, and mutability.
- **Task 29**: Blog post about Python's object model (see
  linked article).
