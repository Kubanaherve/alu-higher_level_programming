# JavaScript Warm Up

Basic JavaScript scripts using `console.log`, `process.argv`, loops,
conditions and functions (no `var`).

| File | Description |
|---|---|
| `0-javascript_is_amazing.js` | Prints `JavaScript is amazing` via `myVar` |
| `1-multi_languages.js` | Prints 3 language lines |
| `2-arguments.js` | Prints argument count message |
| `3-value_argument.js` | Prints first argument or `No argument` (no `length`) |
| `4-concat.js` | Prints `<a> is <b>` |
| `5-to_integer.js` | Prints `My number: <int>` or `Not a number` (no `try/catch`) |
| `6-multi_languages_loop.js` | Same as 1 but with array + loop, one `console.log`, no `if/else` |
| `7-multi_c.js` | Prints `C is fun` x times, two `console.log`, loop required |
| `8-square.js` | Prints `X` square or `Missing size`, loop required |
| `9-add.js` | `function add(a, b)` prints addition |
| `10-factorial.js` | Recursive factorial, `NaN` → `1` |
| `11-second_biggest.js` | Second biggest integer or `0` |
| `12-object.js` | Replaces `12` with `89` in `myObject` |
| `13-add.js` | Exports `add` function (`exports.add`) |
