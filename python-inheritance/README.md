# Python - Inheritance

This project covers class inheritance in Python, including superclass and
subclass relationships, method overriding, the `super()` function, and
built-in functions like `isinstance()`, `issubclass()`, `type()`, and
`dir()`.

## Tasks

- **0-lookup.py**: Returns a list of available attributes and methods
  of an object using `dir()`.
- **1-my_list.py**: `MyList` class inheriting from `list` with
  `print_sorted()` method.
- **2-is_same_class.py**: Returns `True` if object is exactly an instance
  of the specified class.
- **3-is_kind_of_class.py**: Returns `True` if object is an instance or
  inherits from the specified class.
- **4-inherits_from.py**: Returns `True` if object inherited from the
  specified class (excluding exact match).
- **5-base_geometry.py**: Empty `BaseGeometry` class.
- **6-base_geometry.py**: `BaseGeometry` with `area()` method raising an
  exception.
- **7-base_geometry.py**: `BaseGeometry` with `integer_validator()` method.
- **8-rectangle.py**: `Rectangle` class inheriting from `BaseGeometry`.
- **9-rectangle.py**: `Rectangle` with `area()` and `__str__()` methods.
- **10-square.py**: `Square` class inheriting from `Rectangle`.
- **11-square.py**: `Square` with its own `__str__()` method.
